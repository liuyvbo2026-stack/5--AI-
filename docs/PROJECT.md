# 产品范围与技术方案

## 核心流程

邀请码验证 → 上传两张经授权的成年人照片 → 基础质量检查 → 推荐或选择风格 → 摄影风格配置组装提示词 → 服务端调用 Seedream 5.0 pro → 结果预览下载。用户不需要编写提示词，也不填写爱情访谈。

P0：Web 首页；双图上传、预览、更换；基础质量检查；六套 JSON 摄影风格与默认推荐/切换；真实 API 单图生成；结果预览下载；一次性邀请码；服务端 API Key；状态和错误提示。

P1：可靠的视觉分析与智能推荐、单张重生成、更多风格、自动质量评估、模板管理。P2：老年专项、年轻容貌艺术化还原、儿童写真、支付、会员、多模型、视频。未经研究验证不得称某风格为“市场爆款”，也不得擅自抓取或商用他人的作品。

## 简单实现路线

目标技术栈优先 Next.js、TypeScript、Tailwind CSS。**现有代码是 Node.js 原生服务与静态网页**，是否迁移框架要在真实 API 调用验证后再决定，避免两天内把时间花在重写骨架上。AI 流程可用普通服务端函数组织：输入校验、风格路由、提示词构建、Seedream 调用、结果检查；不需要独立 Agent 或微服务。

首版六套风格：韩式极简、复古胶片、新中式婚礼、江南电影感、欧式花园、时尚大片。每条 JSON 需包含名称、场景、服装、姿势、构图、光影、色调、质感、完整提示词、身份保持要求、版本和测试状态。

[火山方舟官方图片生成 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)列明 Seedream 5.0 pro 支持多参考图生成单图。当前账号的模型权限、余额、成本、双人一致性和真实结果均未验证。真实 Key 只由服务端环境变量读取，不输出到聊天、前端、GitHub 或日志。官方 URL 结果有时效性，若使用该返回格式应让用户及时下载。

## 邀请码和隐私

邀请码由服务端验证。建议状态 `unused → reserved → used`，以数据库原子更新或事务保证同一码只有一个任务能占用。成功核销；明确失败才恢复；结果不确定转 `needs_review`，不可盲目释放。选用持久化数据库与部署平台后才能验收并发安全。邀请码管理入口必须受保护。

只接受经同意的成年人照片。旧故事原型含存储原图逻辑，不能未经评估直接用于新公开服务。确定留存期限、部署位置、访问控制和清理机制后再向真实用户开放。

## 真实验收

留下不含敏感信息的真实 API 成功记录；人工检查图片可预览下载、双人身份和明显错误。基础检查至少覆盖两张都已提供、格式、大小及文件可读取。没有可靠视觉服务时，不宣称已自动识别人脸数量或遮挡。
