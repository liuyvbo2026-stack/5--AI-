# 六名组员能力调查

已知团队七人（含组长）均有 GitHub 账号，至少一人学过前端，至少一人学过医疗信息化交付。六名组员的具体账号、能力和可投入时间尚未确认，因此旧 Issue 的角色名不能当作真实负责人。

请每人提供：称呼和 GitHub 用户名；做过的页面/接口/测试/部署；常用 Codex 或 Claude Code 及额度限制；未来两天每天可投入时间；能否独立运行项目；是否会建分支、提交、提 PR；希望承担的任务。不需提供密码或密钥。

收齐后按半天到两天的交付物分工，每人有明确验收标准。任务可覆盖页面、风格配置、Seedream 服务端接入、邀请码、测试、部署和视觉研究。不得依据旧 Issue 直接派发“回忆/三幕/人工交付”任务。
